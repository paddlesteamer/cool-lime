# Cool-Lime — Plan

GUI harness that glues Claude Code sessions into projects with shared context.

## Stack
Electron + electron-vite + React + TypeScript. `node-pty` + `@xterm/xterm` for the Claude terminal,
CodeMirror (`@uiw/react-codemirror`) for the editor, `chokidar` for file watching.

## Layout
- Start screen: Create project / Open recent (registry at `~/.cool-lime/projects.json`).
- Sidebar: projects, subtopics, "+ subtopic", project settings (context, MCPs).
- Left pane: xterm attached to `claude --dangerously-skip-permissions`, cwd = subtopic folder. One pty per subtopic, kept alive across tab switches.
- Right pane: file tree of subtopic folder + editor. Auto-reload on disk change unless buffer is dirty (then show banner).

## Project on disk  (`~/CoolLime/<project>/`)
```
cool-lime.json      manifest: name, created, subtopics[], mcps.project[], mcps.subtopic{}
context/            raw inputs: pasted text (.md) + uploaded pdf/docx/csv/md
CONTEXT.md          distilled shared context (generated by headless claude)
<subtopic>/
  CLAUDE.md         "@../CONTEXT.md" import + "## Subtopic notes" + scratchpad instruction
  .mcp.json         written by `claude mcp add -s project` (project MCPs + subtopic MCPs)
  scratchpad/       agent working files, editable in right pane
```

## Context sharing
Every subtopic CLAUDE.md imports `../CONTEXT.md` (Claude Code `@path` import) → one source of truth, no agent needed for propagation.
Headless `claude -p` runs (serialized, debounced ~2s, self-writes ignored) only when:
- `context/*` changes → regenerate CONTEXT.md from the docs.
- `<subtopic>/CLAUDE.md` changes → distill project-wide facts into CONTEXT.md.

## MCP
Stored in cool-lime.json. Applied with `claude mcp add -s project ...` run inside each subtopic folder
(all folders for project-wide, one folder for subtopic-only); `claude mcp remove -s project` on delete.
Applied again when a new subtopic is created.

## Milestones
1. Shell: Electron + React, start screen, registry, create/open project, sidebar.
2. Terminal: pty per subtopic, tab switching, resize.
3. Right pane: file tree + editor + save + live reload.
4. Context pipeline: intake, CONTEXT.md generation, CLAUDE.md templates, watcher + headless agent.
5. MCP UI + settings.
6. Later: multiple terminals per subtopic, git integration, electron-builder packaging.
